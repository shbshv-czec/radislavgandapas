# radislavgandapas

Черновик одностраничного сайта. Обычная статика: HTML + CSS + один файл JS.
Ни сборки, ни зависимостей, ни внешних запросов — папку можно положить
в GitHub Pages как есть.

## Структура

```
index.html                 разметка, мета-теги, Schema.org
assets/css/styles.css      токены, компоненты, адаптив
assets/js/app.js           меню, появление блоков, счётчики, параллакс, видео
assets/fonts/*.woff2       Oswald, Golos Text, JetBrains Mono (кириллица + латиница)
assets/img/*.webp          фотографии и логотипы клиентов
assets/img/og-image.jpg    превью для Telegram, WhatsApp и соцсетей
robots.txt, sitemap.xml    для поисковиков
_headers                   заголовки для Cloudflare Pages (см. ниже)
.nojekyll                  отключает обработку Jekyll на GitHub Pages
```

## Что изменилось при чистке

Оформление не трогали: высота страницы, все секции и все изображения
остались на прежних местах — сверено с предыдущей версией попиксельно.

**Шрифты теперь свои.** Раньше три семейства грузились с `fonts.googleapis.com`:
отрисовка ждала внешний домен, а IP посетителей уходил третьей стороне.
Скачаны те же вариативные сабсеты (кириллица + латиница), 130 КБ на всё.

**Фотографии в WebP** с вариантами под мобильные через `srcset`. У каждой
картинки проставлены `width`/`height` — раньше их не было ни у одной из 26,
и вёрстка прыгала при загрузке.

**Превью видео лежит локально.** Раньше оно тянулось с `i.ytimg.com` при
каждом заходе. Сам плеер по-прежнему подключается только по клику, и теперь
через `youtube-nocookie.com`.

**Стилей в разметке не осталось.** Все 37 инлайновых `style=` переехали
в классы — иначе строгая политика безопасности не работает.

**Обработчики форм переехали в `app.js`** из атрибутов `onsubmit` по той же
причине. Заодно исправлена опечатка в тексте подтверждения: было
«летит квам на почту».

**Доступность.** У полей форм появились подписи (`<label class="vh">`,
не видна глазом, но доступна скринридеру), `name` и `autocomplete`.
У бургера — `aria-expanded`, меню закрывается по Escape. Кнопка запуска
видео стала настоящей `<button>` — раньше это был `<div>`, недоступный
с клавиатуры. Дубли бегущих строк помечены `aria-hidden`, чтобы список
клиентов не читался дважды.

**Из репозитория убрано 4,3 МБ мусора** — файлы `photo-hero-2.jpg` и
`photo-zayavi.jpg` не были подключены ни одной строкой. Первый при этом
оказался хорошим портретом и занял место полосатой заглушки «Портрет»
в блоке «О Радиславе».

## Что важно знать при правках

**Формы ничего не отправляют.** Это осознанно: черновик. Они просто
показывают подтверждение. Место для подключения приёма заявок помечено
комментарием в конце `assets/js/app.js` — обработчик один на обе формы,
ищите `form[data-fake]`. Текст подтверждения задаётся атрибутом
`data-done` прямо в разметке.

**Заглушки, которые ждут материалов:** обложка подкаста и фото в блоке
«Коучинг». Это полосатые прямоугольники с подписью — как только появятся
файлы, меняются на `<img>` по образцу блока «О Радиславе».

**Строки программ и карточки книг выглядят кликабельными,** но ссылок
за ними нет — у них `cursor:pointer` и стрелка при наведении. Когда
появятся адреса, их стоит сделать настоящими `<a>`: тогда они заработают
и с клавиатуры. Специально не стал подставлять `href="#"` — это создало бы
ссылку в никуда.

**Горизонтальное переполнение.** У `body` стоит `overflow-x:hidden` —
что-то в вёрстке шире экрана, и это прячется, а не чинится. Досталось
от прежней версии, поведение не менял. Если убрать эту строку, станет
видно, какой блок вылезает.

**Дата эфира** («27 июля, 19:00») зашита в разметку без года, поэтому
разметку Schema.org для события не добавлял — поисковик показал бы
неверную дату. Когда дата станет постоянной, стоит добавить блок `Event`.

**Картинки.** Только WebP, без запасных JPEG. Поддержка — все браузеры
с 2020 года. Если меняете фото, пересоберите оба размера и обновите
`width`/`height` в `index.html`, иначе вернутся скачки вёрстки.

## Про заголовки и защиту от вложения в чужой iframe

GitHub Pages не позволяет задавать HTTP-заголовки, поэтому политика
безопасности продублирована в `<meta>` внутри `index.html`. Работает всё,
кроме `frame-ancestors` — эту директиву браузеры в `<meta>` игнорируют
по спецификации. То есть сайт по-прежнему можно вложить в iframe на чужом
домене.

Файл `_headers` готов: на Cloudflare Pages или Netlify он подхватится сам
и добавит `frame-ancestors 'none'`, `X-Content-Type-Options`,
`Permissions-Policy` и долгий кэш для картинок и шрифтов. GitHub Pages
этот файл просто игнорирует.

Хешей в именах файлов намеренно нет: GitHub Pages жёстко отдаёт
`Cache-Control: max-age=600`, переопределить нельзя, выигрыша не будет.
При переезде на Cloudflare Pages кэш уже настроен в `_headers` — вот тогда
хеши имеет смысл добавить.

## Адрес сайта

Прописан в четырёх местах: `<link rel="canonical">`, `og:url`, блок
Schema.org в `index.html` и `sitemap.xml`. При переезде на собственный
домен поменять во всех.

`robots.txt` на проектном адресе `*.github.io/radislavgandapas/` поисковики
читают только из корня домена, так что здесь он начнёт работать после
переезда. `sitemap.xml` можно скормить Search Console напрямую — он
работает с любого пути.
